# Kigyoubunseki15sya
・2023年度 IT業界主要15社の財務・収益分析

・概要
2023年度の国内主要ITベンダー15社（日立製作所、富士通、NTT DATA、オービック、野村総合研究所など）の有価証券報告書等の財務データを用い、企業規模（売上高）と収益性（営業利益率・ROA）・財務健全性（自己資本比率）の相関関係を定量的に分析しました。

#使用技術・環境
言語: Python 3.x
主なライブラリ: pandas, matplotlib, numpy
環境: Google Colab

・分析から得られた主な結果
1.売上高数兆円規模の巨大受託型SIer（日立、富士通、NTT DATA等）は営業利益率4〜8%程度で推移。
2.自社プロダクト展開や直販モデルを持つ高付加価値型企業（オービック、野村総合研究所等）は高い利益率を達成。
3.オービックの圧倒的な財務指標
営業利益率 約63.3%、ROA 約13.2%、自己資本比率 約91.3%を記録。
自社開発ERPの直接販売・直接サポート体制による高収益・高安全性の構造が数値からも明確に裏付けられました。
